任务 01 · 当前请求 ≠ 上次返回

改地址，就已经读了吗？

先预测：把地址 0 写成 42 并读取，再把请求地址改成 1。尚未点击“访问”时，上次返回值是什么？随后访问地址 1，会命中还是缺失？

打开存储层次实验 ↗
  1. 点击“重新开始本演示”。地址设 0、待写字节设 42，执行“写后备存储并失效缓存”。
  2. 执行“访问 / 缺失回填”，记录本次地址、返回值、命中情况，以及回填的两个字节。
  3. 只把地址改为 1，先观察上次读取来源；然后再执行一次访问。
  4. 回放已执行访问，区分“讲解动画”与“再次访问”。

证据：在读取地址 1 后用顶部“保存实验报告”导出报告，并用“导出观察”保存 CSV。报告中的请求与实际访问表应能解释来源。

只读取报告中的状态附件，不运行报告内容；原文件仍需另附。

使用新版存储层次页的“导出观察”。摘要会保存；重新打开本页后，逐行表需重新选择CSV。原文件仍需另附。

教师参考 / 完成后对照

访问 0 首次缺失，回填块 [42, 0]、返回 42。只改地址 1 时，上次读取仍是地址 0 → 42；访问 1 后命中、返回 0。两个地址共享 TAG 与 INDEX，仅 OFFSET 不同。回放不会新增访问。

任务 02 · 同一行 ≠ 同一块

低四位一样，TAG 就相同吗？

本任务使用独立的八位地址标签示例，比上一任务的 16 字节范围更大。预测：地址 0 回填后，请求地址 128，为什么会冲突？

打开缓存门级路线第 2 步 ↗
  1. 地址设 0、回填样本设 42，点击“从下级回填这一行”。再把地址改为 128，暂不回填。
  2. 点击“继续下一步”，检查请求 TAG、保存 TAG、VALID 与 HIT。
  3. 继续进入五位相等电路。找到 bit4 的 XOR，比较两侧输入和输出。
  4. 对比低四位相等与完整五位相等。可展开 XOR/NOT 或对应 AND 门；返回时检查上层状态仍保留。

证据：导出五位相等电路报告，保留具体进入实例；不要只提交一个“EQ=0”截图。

只读取报告中的状态附件，不运行报告内容；原文件仍需另附。

教师参考 / 完成后对照

地址 0 与 128 都选 INDEX=0、OFFSET=0，请求 TAG 分别为 0、16。保存 TAG 仍为 0 且 VALID=1，但完整 TAG 不相等，HIT=0。bit4 输入 1/0，XOR=1、NOT=0；低四位都相同不能推翻这一位的不同。

任务 03 · 相等 ≠ 有效

TAG 全部相同，为什么仍不命中？

打开缓存命中电路 ↗
  1. 请求与保存 TAG 都设 0，VALID 置 0，观察 EQ 和 HIT。
  2. 只把 VALID 置 1。再只把请求 TAG 的 bit4 翻转，比较两次结果。
  3. 展开 AND 门，追踪两个输入分别来自哪里。注意本层比较输入不会改写上级缓存。

证据：导出 AND 门或命中电路报告，包含来源值；说明这是组合判断，不是一次缓存读取。

只读取报告中的状态附件，不运行报告内容；原文件仍需另附。
