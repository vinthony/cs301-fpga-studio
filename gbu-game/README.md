# 芯光计划 · 松山湖校园漫游（开发中）

双击上一级的“启动GBU校园游戏.command”，或在上一级执行 `python3 launcher.py --page game`。需要 Python 3、Icarus Verilog（`iverilog` 和 `vvp`）以及现代浏览器；3D 视图需要 WebGL。游戏、画面素材与仿真在本地运行。

默认进入可拖动旋转、滚轮缩放的 3D 校园；可用 WASD / 方向键移动、E 交互，也可通过右上角切换像素游览。点击“校园导览”可查看 17 个地点并自动前往；走近地点后收集足迹。切换视图时角色会移动到对应视图中最近地标的近似位置，并不保持精确坐标。任务依次在北一门、图书馆、教学楼和产研楼开展，进度保存在本机浏览器。首页“开始新旅程”会在确认后重置进度，“继续旅程”恢复。

图书馆、食堂、宿舍和教学楼附近有可进入的参考室内空间，均为根据有限照片制作的演绎，并非已经确认的实际室内布局。部分实验通过后可在三维校园中回放对应的 RTL 仿真样本。

在三维图书馆附近可点击“观赏‘湾’”，让镜头围绕中央建筑和绿地旋转、缩放；点击“返回人物”或移动角色即可回到游览视角。

三维校园顶部的“地点标识”可开关建筑和道路名称，便于观看屋面；任务站点标记仍会显示。

四项任务分别是组合逻辑、加法、101 状态机与 RISC-V 指令排序。运行验证时调用本地 Icarus Verilog；最后一关使用原教学 RV32I 子集核。游戏不进行 Chisel 编译、FPGA 综合、bit 文件生成或实板验证。

## 校园资料与准确度

本版参照用户提供的三张松山湖校区地图、[公开校园导览图](https://m.dg.bendibao.com/xiuxian/182557.shtm)和[东莞市城建工程管理局的项目航拍与说明](https://dgcjj.dg.gov.cn/gkmlpt/content/4/4319/post_4319157.html)。用户图片存于工作区 `work/gbu-reference/`，仅作为制作参考。以图片中可辨认的“湾”、中央绿地、北一/北二门、教学及科研建筑、三栋宿舍、体育馆和运动场为依据重建布局。

**这仍是待校准的游戏模型，不是完整或测绘级复刻。** 像素游览背景由 AI 依据校园图生成，是一张固定视角的美术演绎；它可能虚构部分建筑、背景、水域和道路。角色与任务标记在其上运动，已有四方向步行动画和部分树木的遮挡、树干碰撞。3D 视图由独立简化模型组成，建筑尺寸、朝向、真实路径、建筑内外细节和部分相对位置尚未逐一核对；校园导览中的行走位置也是估计值。两种视图均未与实测坐标精确配准。

原始参考图中个别活动导览采用示意绘制，与校园导览的透视角度不同。更严格的逐栋复刻需要带尺度的总平面图、多个方位的外立面和道路照片，以及可公开使用的内部资料。封面、树木、角色立绘与步行动画素材为 AI 生成的原创游戏美术；游戏并未使用 Stardew Valley 的素材。Three.js 许可证位于 `../vendor/three/LICENSE`。

## 开源发行说明

发行版不附带外部校园参考图片，导览中使用本项目自绘教学示意图。前述资料仅为制作参考；游戏中的模型与美术是教学演绎。
