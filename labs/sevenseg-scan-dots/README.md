# 四位扫描器与独立小数点整合

运行 `sh run.sh`，需要 Icarus Verilog。随后运行 `node verification/compare_web.cjs /教学应用绝对路径` 可将真实RTL轨迹与网页模型逐行核对，需要 Node.js。

word 为四位十六进制显示字；dot_requests[3:0] 每位1请求对应AN的小数点亮。DP由与网页相同的三个二选一MUX及非门生成；DOTS内部可逐层展开到NOT/AND/OR门。AN0在最右，seg与dp低有效。消隐时an=1111，dp可以保持0，但没有实际发光位。

reset为同步复位，优先于step；step只允许状态推进。每位经过消隐、准备、点亮三个教学阶段。复位状态为AN0点亮阶段，计数循环12阶段。

轨迹包含20组显示字×16点模式×12阶段，共3840状态。另遍历65536显示字的12阶段并检查保持边沿；该遍历的点模式为(word>>4)&15，不声称完整65536×16交叉穷举。VCD只记录3840状态与前置复位，完整遍历不重复输出庞大波形。

下载包记录当前网页数值源文件哈希，后续网页改动应重新核对。此为功能仿真，不提供板级分频器、XDC或实际FPGA部署验证；激励时间间隔不代表物理时序。网页播放每阶段500ms只是观察速度。
