# 小数点四选一：可运行的门级参考

运行 `sh run.sh`，需要 Icarus Verilog 和 Python 3。

`requests[3:0]` 每位 1 表示希望对应 AN 的小数点亮。`digit[1:0]` 选择 AN0…AN3。M0/M1 先按 digit[0] 选择组内请求，M2 按 digit[1] 选择高低组，INV 生成低有效 dp。每个二选一内部使用 NOT、AND、OR 门。

测试遍历全部 64 种输入，记录三处内部结果和 dp，以独立整数取位算法核对。`evidence/dotselect.vcd` 包含所有门级信号，可用波形查看器展开 M0/M1/M2。

这是组合电路，没有时钟或位选使能。dp=0 只是点亮请求，实际发光还要求对应 AN 接通。波形中的 1 ns 是测试激励间隔，不是物理传播延迟。没有验证实际 FPGA 下载、引脚约束、电流、亮度或时序收敛。此包与原固定 dp=1 的扫描器包分开保存。
