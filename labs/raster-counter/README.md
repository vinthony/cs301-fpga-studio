# 十位扫描计数器 · 功能级 RTL 参考

本工程对应 GBU-CS301 可视化的 `rastercounter`：10位共同保存、完整10位终值相等比较、11位加一观察、同步CE与同步RESET。直接手写 Verilog，不是 Chisel 生成工程。

## 行为

- `increment` 保留11位，能表示1023+1=1024。
- `terminal` 只比较 `q == limit`，不是大于等于。
- `d` 在终值相等时为0，否则取加一结果低10位。
- 上升沿 `reset` 优先清零；否则 `enable` 有效时保存 `d`，无效时保持。
- 改变终值、使能或复位本身，不产生边沿、不立刻改写 `q`。
- 终值改到比当前值小时，会先自然经过1023→0，再计到该终值。
- 硬件上电值未指定；使用一个有效同步复位边沿建立已知状态。网页“装载起点”是独立实验初始化，不对应本模块的硬件输入。

## 复验

需要 Python 3.11+、Icarus Verilog (`iverilog` / `vvp`)。在此目录运行：

```sh
python3 verification/check.py
```

穷举1024个当前值 × 1024个终值 × 两种CE × 两种RESET，共4,194,304种转换；另有33,201个连续边沿，覆盖799/520/0/1023/255/17终值、暂停、同步复位、动态终值及固定种子随机控制。每个向量检查边沿前Q、11位加一、相等比较、候选D、下一Q，以及边沿后的实际Q。大向量在临时目录生成，测试后删除。

穷举阶段的任意Q由测试台直接注入，**不意味着硬件有任意装载接口**；连续阶段没有逐拍注入，旧Q来自上次真实捕获结果。Python整数参考与Verilog分别实现，仿真器实际执行RTL。

若同时拥有网页源码，可运行：

```sh
python3 verification/check.py --web-root /absolute/path/to/芯片细胞实验室
```

网页对照读取同一批Python向量，逐条检查组合候选、实际提交值与边沿记录。默认解压包仅包含硬件参考；没有网页源码时不执行网页对照。网页来源文件的SHA-256记录在evidence中，表示验证当时的版本。

## 波形与证据

- `evidence/verification.json`：向量数量、哈希和验证边界。
- `evidence/rtl.log`：实际RTL运行结果。
- `evidence/sample.vcd`、`sample-vectors.txt`：前1500个连续边沿的实际仿真波形及对应输入/期望；可用波形查看器打开VCD。
- `evidence/web.json`：打包时网页对照结果；重新运行且未提供网页目录时不会刷新该证据。

VCD中的时间间隔是测试台节奏，不是25MHz像素时钟、物理传播延迟或可达到频率。

## 尚未证明

本工程不包含VGA水平/垂直计数器联动、同步信号、帧缓冲、RGB端口、PLL/时钟生成、板卡XDC、综合资源、布局布线、建立保持时间或实体板运行验证。十位电路的功能对照不能替代完整VGA和物理FPGA验证。
