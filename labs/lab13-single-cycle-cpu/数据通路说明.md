# Lab13 数据通路与控制表

数据通路.svg是网页CPU在初始循环程序下的功能图快照，按教学布局绘制；它对应SingleCycleCPU.scala的功能路径，不是从生成Verilog反推的制造网表。

1. PC保存当前取指地址。外部组合指令口提供instruction和instructionValid；模块不内置程序ROM。
2. Decoder32产生控制字、立即数及格式/ALU选择。RegFile32从保存数组rawA/rawB读两个源值；x0硬置零。单周期路径关闭旁路，避免待写数据反馈进当前运算。
3. ALU的A按usePC选PC或源寄存器，B按useImm选立即数或第二源寄存器。
4. branchKind用原寄存器值进行相等、有符号或无符号比较。JAL/成立分支目标为PC+立即数；JALR目标为ALU结果并清除最低位。
5. 数据RAM为256个8位寄存器，小端组合读、边沿写。SB/SH/SW只写对应字节；LB/LH按符号扩展，LBU/LHU零扩展。它不保证综合为厂商块RAM。
6. WB由control[13:12]选ALU、MEM、PC+4或IMM。写回、PC、退休计数及存储器/I/O只在step有效且没有故障时一起提交。
7. 故障优先级：当前取指对齐、取指有效、指令合法、已选跳转目标对齐、数据访问对齐、访问范围、ECALL/EBREAK。故障仅保存暂停原因与faultValue；原PC、目的寄存器和数据存储保持，故障指令不退休。

控制信号表.csv从本包实际DecoderTable.scala的40行导出，属于实现对应表，不是独立验证参考。独立验证由verification/reference/rv32_interpreter.py执行。control位0..11依次为valid/useRS1/useRS2/regWrite/memRead/memWrite/branch/jump/useImm/usePC/trap/fence；13:12为WB（0ALU、1MEM、2PC+4、3IMM），15:14为粒度（0字节、1半字、2字）。ALU编码依次ADD/SUB/AND/OR/XOR/SLL/SRL/SRA/SLT/SLTU。format编码0R、1I、2S、3B、4U、5J、6无立即数、7无效。

对照控制表时，还要检查effectiveRegWrite对x0的屏蔽，以及commit对step/clear/reset/halted/fault的门控；表内regWrite=1不代表故障或暂停时仍会写入。
